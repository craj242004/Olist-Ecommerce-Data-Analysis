# 🛒 Olist E-commerce Data Analysis

## 📌 Project Overview

This project analyzes the Brazilian Olist e-commerce dataset using Python and PostgreSQL.

The project focuses on two major stages of the data analytics workflow:

1. Data cleaning and transformation using Python
2. Business analysis using PostgreSQL

The analysis covers **99,441 orders**, **96,096 unique customers**, **112,650 order-item records**, **32,951 products**, **3,095 sellers**, and **99,224 reviews**.

The goal was to transform raw multi-table e-commerce data into analysis-ready datasets and answer practical business questions related to sales, customers, products, sellers, payments, delivery performance, and customer satisfaction.

---

## 🎯 Business Objective

The objective of this project is to understand the performance of an e-commerce marketplace through data cleaning, relational data analysis, and SQL-based business questions.

The analysis focuses on:

- Sales and order performance
- Product and category performance
- Customer behavior
- Seller performance
- Payment trends
- Delivery performance
- Customer satisfaction
- Geographic data quality
- Business KPIs
